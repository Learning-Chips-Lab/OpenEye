OpenEye FPGA Wrapper
====================

This section provides detailed technical documentation for ``OpenEye_FPGA``, the top-level
FPGA wrapper module that adapts the OpenEye neural-network inference accelerator core to an
FPGA platform with DMA burst interfaces and block-RAM buffers.
